# RentalApp

Rental application management for a property management company. ASP.NET Core MVC on .NET 10, Razor views, EF Core, ASP.NET Identity.

## Requirements

- .NET 10 SDK

## Run

```bash
dotnet tool restore
cd src/RentalApp.Web
dotnet watch
```

## Test

```bash
dotnet test
```

## Layout

- `src/RentalApp.Web` web application
- `tests/RentalApp.Tests` xUnit tests
- `LARAVEL-MAP.md` notes mapping .NET concepts to Laravel equivalents

Setup notes, seeded logins, and design decisions are added as the project progresses.
